Study notes

Fifteen notebooks, 1,067 pages

For each project I wrote up what I learned — the problem, the mathematics derived from first principles, a guided tour of the code, worked numerical examples, exercises with solutions, and a step-by-step runbook. Writing them is how I found out which parts I did not actually understand, so they are as much for me as for anyone reading.

Every code listing is extracted from the repository at build time, so a book cannot drift from the code it describes. Each one is a PDF in its project's docs/ folder.
